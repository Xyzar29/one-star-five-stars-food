A one-sentence, one-star review of Earth written by an alien tourist — who
still gives five stars for the food. Built for the make.fun competition
[One Star, Five Stars for the Food](https://make.fun/competitions/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

It writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> One star: Earth towed my saucer, charged me rent for the air, and honked at me in a language I don't speak — but the dumplings were worth the nine-light-year trip.
